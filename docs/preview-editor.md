# 预览页面基础编辑

现有生成会话中的沙箱 HTML 页面完成生成、AI 空闲后，默认进入编辑状态。点击“交互预览”可正常操作页面，点击“返回编辑”恢复编辑。React 内置组件不提供编辑功能。

- 鼠标经过元素时显示蓝色矩形框。单击后显示选框、八方向缩放手柄和分类工具条；拖动选框上方的手柄移动位置。偏移使用独立 CSS `translate`，保留文档流占位和原有 `transform`。
- 缩放修改实际宽高，可能使相邻内容重新排列。图片默认锁定比例，可在工具条中解锁；拖动左边或上边时同时调整偏移，保持对边的位置。行内文字、带旋转或缩放变换的元素暂不显示尺寸手柄，仍可移动；文字大小通过字号调整。
- 双击静态文字进入编辑。失焦提交，Esc 取消；粘贴按纯文本处理。嵌套标签保留，只修改点击位置对应的文本节点。换行的显示遵循页面原有的空白样式。
- 编辑模式中阻止页面链接、按钮和表单操作，切换到交互预览后恢复。

工具条固定在预览区域顶部，根据选中元素切换工具：

工具条及移动手柄均使用 SVG 图标，不常驻显示文字标签；悬停显示中文功能提示，并保留读屏名称。宽高、字号、边框和圆角保留可编辑数值，对齐使用四个图标按钮。

| 类型 | 工具 |
| --- | --- |
| 通用 | 撤销、重做、宽高（可缩放元素） |
| 文字 | 修改文字、字号、加粗、斜体、颜色、对齐 |
| 图片 | 替换图片、锁定比例、边框、圆角 |
| 按钮 | 修改文字、字号、加粗、斜体、文字/背景颜色、边框、圆角 |
| 容器 | 背景、边框、圆角 |
| Canvas / 3D | 仅整体移动 |

撤销/重做记录当前预览内最近 100 次操作，刷新后重新开始记录；它们也会同步源码并自动保存。图片替换复用本地上传接口，并清理对应 `srcset`、`sizes` 和 `<picture>` 的旧图片来源；撤销会恢复这些属性。上传中发送提示词或导出时，会先等待图片替换完成。

每次拖动结束或文字提交后，源码立即更新，约 650 毫秒合并保存到当前生成会话。工具栏显示保存状态；保存失败时保留内存草稿并提供重试。“保存页面”仍是显式保存操作，不会为每次编辑创建历史版本。

查看、保存、复制和下载读取修改后的源码。再次发送提示词前会提交当前文字、结束拖动、保存会话，并将当前选中页面的最新源码作为 Agent 的修改基础；保存失败时不发送需求。AI 运行期间关闭编辑，新生成页面成为新的编辑基础。

“查看页面”提前准备真实的 `/view/...` 地址，直接在新标签页打开。新标签页等待当前文字提交及图片上传完成，再载入这次点击对应的独立快照；编辑模式下无需先关闭编辑。不依赖 `about:blank` 窗口跳转，预览失败会在编辑页显示重试提示。临时预览写入 `.data/views`（沿用 `HISTORY_DATA_DIR`），最多保留 200 份、约 24 小时，服务重启或开发热更新后仍可读取；显式保存的页面仍使用持久化历史记录。

编辑器保持在原有隔离沙箱中，消息同时校验 iframe 来源和每个沙箱独立的随机通道。只修改能映射回源码的节点，避免导出运行时 DOM、事件绑定、选框和手柄。`html/body`、文档元数据、脚本、样式及编辑器自身受保护。Canvas、SVG、3D 场景只能作为整体移动；脚本生成的节点不单独开放编辑，绘制内容不能修改文字。

扩展方式：`editor-toolbar.tsx` 的 `TOOLBAR_TOOLS` 注册各元素类型的控件；`editor-engine.ts` 处理沙箱选框、拖动和操作历史；`editor-source.ts` 校验允许修改的样式和图片属性并更新源码。新增样式控件时同时扩展工具配置与样式白名单。

此版本没有删除、裁剪、旋转、AI 局部编辑或自由画布排版，也未重新发布云端演示。
